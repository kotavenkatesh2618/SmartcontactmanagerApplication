# Smart Contact Manager

A web-based contact management application built with **Spring Boot**, **Thymeleaf**, and **Oracle Database**.  
Smart Contact Manager helps users securely register, log in, and manage personal or professional contacts from one simple dashboard.

## Features

### User Authentication
- User registration and login
- Password encryption
- Role-based access support

### Contact Management
- Add new contacts
- Edit existing contacts
- Delete contacts
- Upload contact profile images
- View user-specific contact lists

### Search and Filter
- Search contacts by name or email
- View contacts with or without profile images

### Data Persistence
- Oracle Database integration
- Spring Data JPA and Hibernate ORM
- Entity validation using Hibernate Validator

## Technology Stack

| Layer | Technology |
|---|---|
| Backend | Spring Boot 3.3.4 |
| Frontend | Thymeleaf, HTML5, CSS3 |
| Database | Oracle Database |
| ORM | Spring Data JPA, Hibernate |
| Build Tool | Maven |
| IDE | Spring Tool Suite |

## Prerequisites

Before running this project, make sure you have installed:

- Java JDK 17 or above
- Maven
- Oracle Database
- Spring Tool Suite or any Java IDE
- Git
